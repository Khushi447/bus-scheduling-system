# 🚌 Bus Scheduling and Route Management System

A modern web-based **Bus Scheduling and Route Management System** designed to simplify and automate bus operations for drivers, conductors, and transport administrators.

---

## 🚀 Project Overview

This project is built to manage:
- Crew scheduling (drivers & conductors)
- Linked duty assignments
- Independent (unlinked) shift management
- Route visualization and planning
- Interactive map-based route management

The system aims to reduce manual scheduling conflicts and improve efficiency in public transport operations.

---

## ✨ Current Features (Frontend Completed)

### 👥 Crew Management
- Crew selection dashboard
- Navigation between scheduling modules

### 🔗 Linked Scheduling
- Assign driver and conductor together
- Shift time input
- Overlap detection logic (basic validation)
- Instant feedback for scheduling conflicts

### 🔓 Unlinked Scheduling
- Independent duty assignment system
- Flexible shift management

### 🗺️ Route Management
- Interactive map integration using Leaflet
- Display of multiple routes
- Route visualization with markers and polylines
- Sidebar controls for route actions

### 🎨 UI/UX
- Responsive modern UI
- Clean card-based layout
- Light blue professional theme
- Animated transitions and hover effects
